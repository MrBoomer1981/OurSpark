# OurSpark — фото дня на двоих

Telegram-бот для пар. Утром приходит тема, днём каждый фотографирует и присылает фото, вечером — обмен: каждый видит фото другого. Один бот обслуживает сколько угодно пар, у каждой своя игра.

## Как пользоваться

1. Открой бота, нажми «Старт», затем «💞 Создать пару».
2. Перешли полученную ссылку тому, с кем хочешь играть. Как только партнёр её откроет, пара собрана.
3. Каждое утро (по умолчанию в 9:00) приходит тема. Присылай фото — обычным фото или файлом без сжатия.
4. Вечером (по умолчанию в 21:00) — обмен. Фото партнёра видит только тот, кто прислал своё. Не успеваешь — можно дослать до полуночи, и обмен случится сразу.
5. Если фото уже у обоих, можно открыть раньше: когда вы оба нажмёте «🔓 Открыть сейчас».

| Команда | Что делает |
|---|---|
| `/today` | тема и статус дня |
| `/history` | архив, серия и рекорд |
| `/addtheme` | предложить тему — она выпадет в один из ближайших дней с подписью автора |
| `/settings` | время темы, время обмена и часовой пояс пары |
| `/leave` | выйти из пары |
| `/help` | правила коротко |

Ещё в боте есть:
- **«Другая тема».** До 3 раз в день, пока никто не прислал фото, и всегда простая.
- **Напоминание.** Приходит за 3 часа до обмена тому, у кого ещё нет фото.
- **Реакции и ответы.** После обмена можно поставить реакцию кнопкой, а ответ (reply) на фото бот перешлёт партнёру.
- **Серия.** Считает дни подряд с обменом, отмечает вехи и рекорд.

## Что бот хранит

- **Об участниках:** имя и Telegram ID, а также в какой паре человек состоит.
- **О днях:** темы, время событий, реакции и подписи к фото.
- **Фото — только ссылки (`file_id`).** Сами файлы хранит Telegram, у бота их нет.
- **Ответы на фото бот только пересылает партнёру** и не сохраняет.

Пары друг друга не видят. После `/leave` история пары остаётся в базе, но доступа к ней больше нет.

## Как поднять своего бота

Нужны аккаунты GitHub и Railway.

1. **Бот.** В [@BotFather](https://t.me/BotFather) отправь `/newbot`, задай имя и username, сохрани токен.
2. **Код.** Форкни этот репозиторий.
3. **Railway.** New Project → Deploy from GitHub repo → выбери форк. Railway сам соберёт его по `Dockerfile`. Регион лучше европейский: он ближе к серверам Telegram, и бот отвечает быстрее.
4. **Volume.** Подключи к сервису Volume с путём `/app/data`, там живёт база. Без Volume бот не запустится: это защита, чтобы деплой не стёр данные.
5. **Переменные.** Обязательна `BOT_TOKEN`, остальные — по желанию (таблица ниже).
6. **Готово.** Открой своего бота → `/start` → «Создать пару».

Дальше каждый push в `main` — новый деплой. Деплоить можно когда угодно, даже днём: фото, присланные до или во время деплоя, не теряются. После старта в логах видна строка «База: … · пар: … · участников: …».

| Переменная | По умолчанию | Что это |
|---|---|---|
| `BOT_TOKEN` | — | токен от @BotFather |
| `TIMEZONE` | `Europe/Moscow` | часовой пояс новых пар; каждая пара может сменить свой в `/settings` |
| `NEW_PAIRS` | `true` | `false` закрывает приём новых пар, собранные пары играют дальше |
| `DEBUG` | `false` | `true` включает `/dev` (запуск событий дня без ожидания) и подробные логи |
| `DB_PATH` | `data/bot.db` | путь к базе SQLite |

### Локальный запуск

Нужен **отдельный тестовый бот**: один токен нельзя слушать из двух мест, иначе прод и локальная копия будут отнимать друг у друга обновления.

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # вписать токен тестового бота
python -m bot
```

### Темы

Темы лежат в двух файлах, одна строка — одна тема в формате `Название — подсказка`:

- `themes/simple.txt` — простые, такие можно снять за минуту там, где ты сейчас. Выпадают в 70% дней.
- `themes/creative.txt` — посложнее: надо подумать или что-то поискать. Выпадают в 30% дней.

Тема, по которой пара прислала фото, для этой пары больше не выпадает. Названия не должны повторяться ни в одном из двух файлов.

### Как устроено

Бот написан на Python 3.12 и aiogram 3, данные лежат в SQLite на Railway Volume. Каждая фишка — отдельный модуль в `bot/features/` и подключается одной строкой в `bot/features/__init__.py`. Схема базы меняется только новой миграцией в конце `MIGRATIONS` в `bot/db.py`. Подробности — в [docs/photo-bot.md](docs/photo-bot.md) и [CLAUDE.md](CLAUDE.md).
